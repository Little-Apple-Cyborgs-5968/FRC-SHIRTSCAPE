# FRC-SHIRTSCAPE
FRC SHIRTSCAPE is an offseason challenge created by Team 5968 aimed at preparing new robotics club members for the real season.


Our main goals for this project were:

-Create a Game that is accesbile and feasible to acomplish for teams without a lot of resources and space 

-Create a Game that teaches all important aspect of a real FRC season, preparing student for success.

-Build a cool robot that launched shirts for showing off at events
